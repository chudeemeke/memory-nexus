## Goal

Export `SearchMode`, `HybridSearchOptions`, `IStatsService`, `StatsResult`, and `ProjectStats` from the public API surface (`@chude/memory` entry point) so TypeScript consumers can import them by name. Add integration tests that verify the exports resolve from `src/index.ts`. Document the newly-exported types in the README API reference.

## Why

The integration checker identified two gaps (MISSING-01, MISSING-02): `domain/ports/index.ts` only exports `ISearchService` and `SearchOptions` from `services.ts`, omitting five other types that consumers need for typed search and stats operations. Additionally, `domain/index.ts` does not re-export the ports barrel at all, so even the types that ARE in `domain/ports/index.ts` only reach consumers because of the explicit `export *` chain through `domain/index.ts` -> `src/index.ts`. This plan fixes both levels: the ports barrel omission and the domain barrel gap.
