# Summary 38.1-01: Canonical Event Kernel and Projection Replay

## Completed

- Added `MemoryEventEnvelope` as the schema-versioned v2 event source-of-truth record with event identity, machine identity, sequence, scope, provenance, privacy, consent, causality, payload, and SHA-256 integrity metadata.
- Added deterministic payload and envelope integrity verification so persisted event records reject payload tampering, envelope tampering, malformed dates, invalid scope, invalid privacy state, invalid consent state, and missing identity.
- Added `ProjectionRegistry` in the application layer so projections declare consumed event kinds, reset before replay, skip duplicate event ids, and return replay evidence.
- Reworked `event-log.ts` so `appendEvent`, `readEvents`, and `rebuildProjections` remain compatible while using canonical v2 envelopes internally.
- Added `appendMemoryEvent`, `readMemoryEvents`, `readMemoryEventsWithReport`, and `rebuildProjectionsWithReport` for canonical event consumers and structured invalid-line reporting.
- Added a v1 fact-shaped event adapter so existing JSONL records replay without data loss, including uuid, type, project, content, metadata, observed time, supersedence state, sequence, and redaction metadata.
- Wired the current facts projection through the registry. Facts FTS remains rebuilt by existing SQLite triggers after facts projection writes.

## Deliberate Boundaries

- Remote sync remains gated by `MEMORY_EXPERIMENTAL_REMOTE_SYNC=1`; Phase 38.1 did not make remote sync production-ready or register the public remote command by default.
- Privacy and consent are represented in the event envelope, but enforcement before storage, indexing, export, provider egress, and remote sync is Phase 38.2 and Phase 38.2.5 work.
- Persona, graph, ranking, dreaming, friction contract, and richer governance projections remain owned by later roadmap phases and must use the projection registry when those canonical event kinds become applicable.
- No stated or inferred feature was removed to simplify the phase.
