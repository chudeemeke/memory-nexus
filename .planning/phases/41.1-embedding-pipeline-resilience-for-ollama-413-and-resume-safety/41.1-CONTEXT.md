<domain>
## Phase Boundary

This phase fixes embedding pipeline resilience only. It must make `memory sync --embed` progress across oversized provider requests and must do so without project-specific or provider-specific coupling in the application layer.

Out of scope:
- Replacing Ollama, Tailscale, nginx, or provider-egress policy.
- Completing Phase 42 dreaming.
- Broad GSD health cleanup for old phase directory drift.
- Making `authkey` a dependency.
</domain>

<decisions>
## Implementation Decisions

### First Principles

- Embedding sync is corpus processing. It needs monotonic progress, durable failure classification, and safe resumability.
- Request-size limits are a provider/transport property. The application must not assume `batchSize` alone proves request safety.
- Multi-item oversized batches are retryable by partitioning. A single oversized item is not retryable by further splitting without changing semantic input.
- Failure metadata must be privacy-safe. Store ids, model/provider, byte count, reason, retryability, and content hash/fingerprint; do not store raw text.
- Skip/quarantine state must be model-scoped so a future model or configuration can retry honestly.

### Locked Decisions

- Keep provider implementations pluggable through existing embedding provider ports.
- Add explicit typed failure for payload-too-large or equivalent request-size failures.
- Ollama must get concrete 413 behavior because the live blocker is Ollama over Tailscale/nginx.
- Application behavior must remain generic for any provider that raises the typed failure.
- Resume must not reselect the same current-model skipped rows.
- CLI output must report skipped rows honestly and safely.

### the agent's Discretion

- Exact table name for durable skip state.
- Exact conservative default payload budget, provided it sits below common reverse-proxy body limits and is configurable.
- Whether adaptive split lives primarily in the provider adapter, service layer, or both, as long as ordering, tests, and loose coupling are preserved.
</decisions>

- Configured embedding provider was Ollama with model `nomic-embed-text`, dimensions `768`, base URL `https://ollama.tail859c3a.ts.net`, and `batchSize` `100`.
