## Sampling Rate

- **After RED tests are added:** Run the focused test command and confirm the new assertions fail for the expected reason.
- **After provider implementation:** Run `bun test src/infrastructure/embedding/ollama-provider.test.ts --timeout 15000`.
- **After service/repository/schema implementation:** Run the focused application/repository/schema test set.
- **After CLI reporting:** Run the focused CLI sync test plus inbox lint.
- **Before phase closure:** Run typecheck, build, eval, inbox lint, and diff whitespace. Run full quality if shared schema/service changes make focused coverage insufficient.
- **Max feedback latency:** one task boundary.
