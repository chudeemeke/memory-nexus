# Plan 14-04: EmbeddingProviderFactory, Config Integration, and Doctor Reporting

## Goal

Implement the `EmbeddingProviderFactory` that creates embedding providers based on configuration, extend the config system to include an `embedding` section, and update the `doctor` command to report sqlite-vec and embedding provider status. The factory uses lazy loading -- it does NOT call `initialize()` on creation. The caller controls when the ONNX runtime loads.

## must_haves

- [ ] `EmbeddingProviderFactory.create(config)` returns an `IEmbeddingProvider` instance based on config (currently only "local" -> TransformersJsProvider)
- [ ] Factory does NOT call `initialize()` -- the returned provider is uninitialized (caller controls ONNX runtime load timing)
- [ ] Factory caches the provider instance (singleton per config) -- calling `create()` twice with same config returns same instance
- [ ] `MemoryConfig` interface extended with optional `embedding?: EmbeddingConfig` section
- [ ] `DEFAULT_CONFIG` extended with default embedding config (enabled: true, provider: "local", model: "Xenova/all-MiniLM-L6-v2", dimensions: 384)
- [ ] `memory doctor` reports sqlite-vec extension status (loaded/not loaded, version if available)
- [ ] `memory doctor` reports embedding config (provider, model, dimensions)
- [ ] `memory doctor --json` includes embedding and sqlite-vec fields in JSON output
- [ ] 95%+ coverage at EACH metric for new and modified files

<task id="14-04-A" title="EmbeddingProviderFactory and config integration (TDD)">

### Context

The factory is the composition root for embedding providers. Phase 17 will add OpenAI and Ollama providers to the factory's registry. For now, only "local" (TransformersJsProvider) is supported. Unknown providers should throw a descriptive error.

The config system in `config-manager.ts` uses a flat `MemoryConfig` interface with `DEFAULT_CONFIG` defaults. Adding an `embedding` section follows the existing merge-on-load pattern: `{ ...DEFAULT_CONFIG, ...loaded }`. Since `embedding` is a nested object, the merge needs to handle partial nested config properly.

**Research finding (Pitfall 2, Dynamic Import Caching):** The factory should cache provider instances. Creating multiple providers for the same config wastes resources. The cache key should include provider type and model name.

Create `src/infrastructure/embedding/embedding-provider-factory.ts`:

```typescript
import type { IEmbeddingProvider } from "../../domain/ports/embedding.js";
import type { EmbeddingConfigData } from "../hooks/config-manager.js";
import { DEFAULT_EMBEDDING_CONFIG } from "../hooks/config-manager.js";
import { TransformersJsProvider } from "./transformers-js-provider.js";

export class EmbeddingProviderFactory {
  private cache = new Map<string, IEmbeddingProvider>();

  private cacheKey(config: EmbeddingConfigData): string {
    return `${config.provider}:${config.model}:${config.dimensions}`;
  }

  create(config: EmbeddingConfigData): IEmbeddingProvider {
    const key = this.cacheKey(config);
    const cached = this.cache.get(key);
    if (cached) return cached;

    let provider: IEmbeddingProvider;
    switch (config.provider) {
      case "local":
        provider = new TransformersJsProvider({
          model: config.model,
          dimensions: config.dimensions,
        });
        break;
      default:
        throw new Error(
          `Unsupported embedding provider: "${config.provider}". Supported: local`
        );
    }

    this.cache.set(key, provider);
    return provider;
  }

  createFromConfig(memoryConfig: { embedding?: EmbeddingConfigData }): IEmbeddingProvider | null {
    const embeddingConfig = memoryConfig.embedding ?? DEFAULT_EMBEDDING_CONFIG;
    if (!embeddingConfig.enabled) return null;
    return this.create(embeddingConfig);
  }

  async dispose(): Promise<void> {
    for (const provider of this.cache.values()) {
      await provider.dispose();
    }
    this.cache.clear();
  }
}
```

```typescript
export function checkSqliteVecAvailability(): SqliteVecHealth {
  try {
    const { Database } = require("bun:sqlite");
    const sqliteVec = require("sqlite-vec");
    const db = new Database(":memory:");
    sqliteVec.load(db);
    const result = db.query("SELECT vec_version()").get() as { "vec_version()": string };
    db.close();
    return { available: true, version: result["vec_version()"] };
  } catch {
    return { available: false, version: null };
  }
}

export function checkEmbeddingConfig(): EmbeddingHealth {
  const config = loadConfig();
  const embedding = config.embedding;
  return {
    configured: true,
    provider: embedding.provider,
    model: embedding.model,
    dimensions: embedding.dimensions,
    enabled: embedding.enabled,
  };
}
```
