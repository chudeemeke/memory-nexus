# Phase 37-01 Plan: Publishing

Status: Blocked by Phase 36.10
Created: 2026-05-30

## Publish Audit Findings

- `npm view @chude/memory version dist-tags --json` returned 404: the package is not visible on the public registry, or the current npm identity lacks access.
- `npm whoami` returned E401: the current shell is not authenticated to npm.
- `package.json` uses a placeholder repository URL: `https://github.com/user/memory-nexus`.
- Current packed files include `README.md`, `package.json`, and `dist/**`; pack size is about 831 KB and unpacked size is about 4.0 MB before build hardening.
- Current `dist` bundles include generated absolute iCloud target paths. Publish builds must avoid leaking local filesystem paths.
- README still presents legacy `~/.memory` / `MEMORY_HOME` as active default storage; Phase 36.10 must resolve this before publish.

## Goal

Publish `@chude/memory` only after local package contents, install behavior, registry auth, and release gates are verified.

## Tasks

1. Complete Phase 36.10.
2. Harden package metadata and build output.
   - Correct repository metadata.
   - Build with external packages/minification or an equivalent path-sanitizing configuration.
   - Verify packed output contains no local absolute paths or source maps.
3. Local install verification.
   - Build.
   - `npm pack --dry-run --json`.
   - Install the tarball into an isolated temp prefix.
   - Verify `memory --version`, `memory --help`, and a non-mutating health command.
4. Registry verification.
   - Confirm npm authentication.
   - Confirm package availability and dist-tag strategy.
   - If first publish, use the scoped public access flag.
5. Release execution.
   - Run final release gates.
   - Publish prerelease first if needed.
   - Verify install from registry before GA tagging.

## Current Blocker

Do not publish while npm auth is E401 or while Phase 36.10 is incomplete.
