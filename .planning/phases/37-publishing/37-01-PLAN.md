# Plan: 37-01-PLAN.md - Package Pre-release & Build Verification

This plan handles the steps required to compile the codebase, bump versioning tags, and locally verify global installability to prepare the tool for User Acceptance Testing (UAT).

## Steps

### 1. Versioning & CHANGELOG Metadata
- [ ] Update `package.json` version to `"4.0.0-pre.1"`.
- [ ] Add the `v4.0.0-pre.1` entry in `CHANGELOG.md` detailing the Event-Log SSOT architecture, temporal facts supersedence events, and T7 plain-text canonical recovery story.

### 2. Compilation & Production Bundling
- [ ] Run the Bun compilation builder:
  ```bash
  bun run build
  ```
- [ ] Verify that all built files compile cleanly into `dist/` and that types generate successfully into `dist/index.d.ts`.

### 3. Comprehensive Quality Gate Validations
- [ ] Run the complete test suite:
  ```bash
  bun test
  ```
- [ ] Run the TypeScript type-safety compiler:
  ```bash
  bun run typecheck
  ```
- [ ] Run the strict test isolation checker:
  ```bash
  bun run test:isolation
  ```

### 4. Local Global Install Smoke Test
- [ ] Clean any development hooks:
  ```bash
  bun run dist/presentation/cli/index.js uninstall
  ```
- [ ] Install the compiled local package globally:
  ```bash
  bun add -g ./
  ```
- [ ] Run `memory --version` to ensure it outputs `4.0.0-pre.1`.
- [ ] Run `memory doctor` to verify hooks, locks, and vector extensions pass.
