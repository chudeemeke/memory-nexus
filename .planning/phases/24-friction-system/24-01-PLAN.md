**SqliteFrictionRepository (src/infrastructure/database/repositories/friction-repository.ts):**

Follow SqliteMemoryFileRepository pattern. Constructor takes Database from bun:sqlite.

Row interface:
```typescript
interface FrictionRow {
  id: number;
  description: string;
  severity: string;
  category: string;
  status: string;
  context: string | null;
  source_project: string | null;
  logged_at: string;
  resolved_at: string | null;
  resolution: string | null;
}
```

Private toEntity(row: FrictionRow): FrictionEntry method to convert DB rows to domain entities.

Methods:
- **save(entry):** INSERT INTO friction_log (...) VALUES (...). Return entity with id from lastInsertRowid.
- **findById(id):** SELECT * FROM friction_log WHERE id = ?. Return null if not found.
- **findOpen():** SELECT * FROM friction_log WHERE status = 'open' ORDER BY logged_at DESC.
- **findAll(options?):** Dynamic WHERE clause building from status, category, limit. ORDER BY logged_at DESC. Default limit 100.
- **resolve(id, resolution):** UPDATE friction_log SET status = 'resolved', resolution = ?, resolved_at = ? WHERE id = ?. Use new Date().toISOString() for resolved_at. Throw if id not found.
- **updateStatus(id, status):** UPDATE friction_log SET status = ? WHERE id = ?. Throw if id not found.
- **getStats():** Single SQL query with aggregations:
  ```sql
  SELECT
    COUNT(*) as total,
    SUM(CASE WHEN status = 'open' THEN 1 ELSE 0 END) as open_count,
    SUM(CASE WHEN status = 'resolved' THEN 1 ELSE 0 END) as resolved_count,
    SUM(CASE WHEN status = 'wont-fix' THEN 1 ELSE 0 END) as wont_fix_count,
    AVG(CASE WHEN resolved_at IS NOT NULL
        THEN julianday(resolved_at) - julianday(logged_at) END) as avg_resolve_days
  FROM friction_log
  ```
  Plus separate queries for bySeverity and byCategory breakdowns (GROUP BY queries).
  Plus query for oldestOpen (WHERE status = 'open' ORDER BY logged_at ASC LIMIT 1, compute daysOpen with julianday('now') - julianday(logged_at)).
- **getWeeklyTrends(weeks):** Use strftime('%Y-W%W', logged_at) for ISO week grouping. Generate expected weeks array first, then query new and resolved counts per week. Return array with zero-filled weeks where no activity.
