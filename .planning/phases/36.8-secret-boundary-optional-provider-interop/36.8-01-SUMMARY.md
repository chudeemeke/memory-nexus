# Summary: Phase 36.8 - Secret Boundary and Optional Provider Interop

## Completed

- Restored gate honesty:
  - `build:types` now runs `tsc --project tsconfig.lib.json` without `|| true`.
  - `tsconfig.lib.json` uses `noEmitOnError: true`.
  - `bun run build` now fails on type errors.
- Restored test isolation:
  - Remote sync command tests use dependency injection instead of first-party `mock.module`.
  - `bun run test:isolation` passes.
- Removed release-blocking dependency audit findings:
  - Updated direct dependencies and lockfile.
  - Added targeted overrides for vulnerable transitives.
  - `bun audit` reports no vulnerabilities.
- Added secret boundary:
  - Added `IRedactor` domain port.
  - Added `PatternRedactor` infrastructure adapter.
  - Redacts known secret shapes without returning raw secret values in findings.
  - Wired redaction into sync persistence, extraction provider payloads, fact event writes, embedding provider payloads, and export.
- Hardened provider secret config:
  - Added `embedding.apiKeyEnv`.
  - Added opaque `embedding.apiKeyRef`.
  - Kept `embedding.apiKey` as deprecated compatibility input only.
  - Health/readiness no longer recommends plaintext `config.embedding.apiKey`.
  - Status JSON redacts deprecated plaintext `embedding.apiKey`.
- Centralized provider support:
  - Added an internal provider registry for embedding and extraction capabilities.
  - `health-checker`, `EmbeddingProviderFactory`, and `memory extract` now use the same provider truth.
  - Unknown providers now report/fail as unsupported instead of silently falling back to `claude-cli` or ready local behavior.
  - Added `openai-compatible` for OpenAI-compatible gateways and self-hosted/proxy providers.
  - Extraction model defaults are separate from embedding model defaults; `LLM_MODEL` is the runtime override.
- Hardened export:
  - `memory export` redacts by default through the CLI.
  - Raw backup output requires explicit `--include-sensitive`.
  - Bash/zsh/fish completions include `--include-sensitive`.
- Documented optional authkey interop:
  - `authkey run --env memory -- memory sync --embed`
  - `authkey run --env memory -- memory extract memory-nexus`
  - No hard authkey dependency.
  - No `authkey get`.
