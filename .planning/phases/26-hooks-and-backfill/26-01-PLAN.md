# Plan 26-01: PreCompact Flush Reminder in Sync Hook Script

## Goal

Add a memory flush reminder message to the PreCompact hook path in `sync-hook-script.ts`. When Claude Code fires the PreCompact event before context compression, the hook outputs a reminder to stdout telling Claude to save important context to `~/.memory/` files. This is a small, targeted modification to an existing code path -- the hook infrastructure already handles PreCompact events, but currently only syncs silently.

## must_haves

- [ ] When `hook_event_name` is `"PreCompact"`, the hook outputs a flush reminder to stdout before checking `syncOnCompaction` config
- [ ] The reminder message includes: "MEMORY FLUSH: Session nearing compaction. Write important context (decisions, unresolved items, learnings) to ~/.memory/ files before context is compressed."
- [ ] The reminder is output regardless of `syncOnCompaction` config (the reminder is always useful; sync is optional)
- [ ] When `hook_event_name` is `"SessionEnd"`, no reminder is output (existing behavior unchanged)
- [ ] When `syncOnCompaction` is false and event is PreCompact, the hook outputs the reminder and exits without spawning sync
- [ ] When `syncOnCompaction` is true and event is PreCompact, the hook outputs the reminder AND spawns background sync
- [ ] All existing sync-hook-script tests continue to pass (no behavioral regression)
- [ ] New tests cover all PreCompact reminder scenarios with 95%+ coverage

### Context

The sync-hook-script at `src/infrastructure/hooks/sync-hook-script.ts` already has a code path for PreCompact events. At line 131, it checks `hookInput.hook_event_name === "PreCompact"` and skips if `!config.syncOnCompaction`. The change adds a `console.log()` output BEFORE this check, so the reminder always appears regardless of the sync config.

Claude Code reads hook stdout output and presents it to the user. The reminder goes to stdout via `console.log()`, which is synchronous in Bun. The hook script already has the `readStdinJson()` function to parse hook input from stdin.

The existing test file is at `src/infrastructure/hooks/sync-hook-script.test.ts`. The tests mock stdin, config, and verify exit behavior.

### Green Phase -- Implement

Modify `src/infrastructure/hooks/sync-hook-script.ts`, in the `main()` function:

After the hookInput is read (line ~128) and BEFORE the `syncOnCompaction` check (line 131), add the PreCompact reminder output:

```typescript
// Output flush reminder for PreCompact (before sync check)
if (hookInput.hook_event_name === "PreCompact") {
    console.log(
        "MEMORY FLUSH: Session nearing compaction. " +
        "Write important context (decisions, unresolved items, learnings) " +
        "to ~/.memory/ files before context is compressed."
    );
}

// Check if this hook type is enabled (existing code at line 131)
if (hookInput.hook_event_name === "PreCompact" && !config.syncOnCompaction) {
    process.exit(0);
}
```

The key ordering: reminder output comes BEFORE the `syncOnCompaction` check. If sync is disabled, the hook still outputs the reminder, then exits. If sync is enabled, the hook outputs the reminder, continues past the check, and spawns background sync.
