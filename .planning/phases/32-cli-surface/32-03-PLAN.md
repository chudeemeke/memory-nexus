**Deprecation semantics (Codex MEDIUM-2):**
- `--format default` on search/list/show/stats: emits one-shot stderr warning, maps to existing default (text) path. Suppressed in `--json` mode.
- `--format detailed` on context/related: emits one-shot stderr warning, maps to existing detailed path. Suppressed in `--json` mode.
- Both aliases are scheduled for removal in next minor; CHANGELOG documents.

Per-formatter `brief` semantics:

| Command | brief output spec |
|---------|-------------------|
| search  | One line per result: `<session-id> [<score>%] <snippet first 80 chars, no markup>` |
| context | One line summary: `<project>: <session_count> sessions, <message_count> messages, last active <relative-time>` |
| show    | One line: `<session-id> | <project> | <message-count> messages | <start_time>` |
| list    | One line per session: `<session-id> <project> <message_count> <last_active>` |
| related | One line per result: `<id> [<score>%] <type>` |
| stats   | Up to 5 lines: counters and labels, no breakdowns. Hard ceiling ≤5 lines. |

Behavior for `--format ai`: unchanged — calls `formatForAi(text)` on default text output.
