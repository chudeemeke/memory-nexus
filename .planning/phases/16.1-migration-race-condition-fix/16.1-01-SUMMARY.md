## Decisions Made
- Size comparison (not timestamp or content hash) determines conflict winner -- simple, correct, fast
- Equal-size files keep destination (no migration needed; prevents unnecessary churn)
- WAL/SHM cleanup only occurs when source is larger (overwrite case), not when destination is kept
- Directory conflicts skip entirely rather than attempting merge (logs, hooks, backups are non-critical)
- isMigrationPending does NOT import into connection.ts -- guard lives at CLI entry point only
