<objective>
Rename all internal type/class identifiers from `memory-nexus` naming to `memory` naming, and update all user-facing strings to reference the `memory` binary. This is the core identity rename across the entire codebase.

Purpose: After Plan 01 centralized paths, this plan handles the remaining identity references: the error class (MemoryNexusError -> MemoryError), config type (MemoryNexusConfig -> MemoryConfig), hook marker (MEMORY_NEXUS_MARKER -> MEMORY_MARKER), environment variable (MEMORY_NEXUS_HOOK -> MEMORY_HOOK), and all user-facing strings in CLI commands. This is the largest mechanical change in the rename -- touching ~55 files -- but each change is a straightforward find-and-replace with careful attention to preserving test data that uses "memory-nexus" as a project name.

Output: All internal identifiers and user-facing strings updated. The codebase internally refers to itself as "memory" everywhere.
</objective>
