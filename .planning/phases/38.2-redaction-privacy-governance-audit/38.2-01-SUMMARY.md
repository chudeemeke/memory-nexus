# Summary 38.2-01: Redaction, Privacy Governance, and Audit Commands

## Completed

- Hardened `PatternRedactor` with stable hashed placeholders, rule version metadata, Tailscale key detection, environment assignment redaction, sensitive JSON-key redaction, and flag-adjacent argument redaction without returning raw values in findings.
- Added `SecretAuditService` to scan database columns and active event logs, report locations and redacted finding metadata only, redact mutable database fields, rebuild FTS indexes, and quarantine raw event logs while writing sanitized active replacements.
- Added top-level `memory audit-secrets` with read-only default scanning, JSON/text output, explicit `--redact-db`, `--quarantine-events`, `--report`, `--skip-db`, `--skip-events`, and event-log selection options.
- Added provider egress policy to config and provider readiness/creation paths. Remote embedding/extraction providers now require explicit consent plus provider/host allowlist; local providers remain exempt.
- Surfaced provider egress readiness in `memory status` and `memory doctor`.
- Redacted additional persistence and egress paths: hook JSONL logs, friction entries, extraction provider payloads, active facts used in embedding comparison, extraction fallback warnings, embedding payloads, and export output by default.
- Added an event-log privacy preflight before the explicitly gated remote-sync prototype can push to Git. If active event logs still contain audit findings, remote sync is blocked and the output gives only finding counts and remediation guidance.
- Exported `executeAuditSecretsCommand` and `AuditSecretsOptions` from the public package root.

## Deliberate Boundaries

- Phase 38.2.5 remains required for durable consent/provenance event types, review/suppression/invalidation workflows, and governance controls over future derived memory surfaces.
- Remote sync remains non-production and gated by `MEMORY_EXPERIMENTAL_REMOTE_SYNC=1`; Phase 38.2 added privacy preflight protection but did not implement Phase 38.3 transport semantics or Phase 38.4 operations.
- `apiKeyRef` remains opaque metadata. `memory` does not resolve raw secret references and does not call `authkey get`.
- Raw export remains available only through explicit `--include-sensitive` for backup workflows.
- No stated, inferred, disabled, prototype, or documented feature was removed to complete the phase.
