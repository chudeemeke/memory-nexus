## Implemented

- Added top-level local maintenance surfaces:
  - `memory backup create [outputDir] --json|--quiet`
  - `memory backup verify <backupPath> --json`
  - `memory restore <backupPath> --dry-run --confirm --json`
- Added `memory projections rebuild --verify --confirm --json` so event-sourced projection replay is publicly operable.
- Hardened `memory migrate` with `--dry-run`, `--json`, and `--confirm`; mutation now requires explicit confirmation.
- Added `memory doctor --upgrade --json` as an upgrade-readiness diagnostic, not a hidden mutation path.
- Updated command registration, shell completion, help grouping snapshots, programmatic exports, and README discovery.
- Hardened qmd executable discovery by replacing shell `which qmd` with PATH/PATHEXT-aware executable lookup.
- Tightened `MemoryEventEnvelope` array validation so invalid metadata arrays are rejected instead of silently coerced.
- Added targeted tests for remote sync fallback errors, migration safe-output paths, ranking fallback policies, backup/restore edge cases, projections, doctor upgrade diagnostics, qmd lookup, and strict memory-event validation.
- Updated the coverage harness source/test target configuration so generated or unrelated local folders do not pollute repository coverage.
