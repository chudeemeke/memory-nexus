If the lock exists but the PID is dead, line 212 calls `removeLock(dataDir)` before proceeding to spawn. 2. **Lines 236-237** -- `subprocess.pid === undefined` branch. After `spawn()` is called, if the OS fails to assign a PID, the function returns `{ started: false, reason: "spawn_failed" }`. This requires mocking `spawn` to return a process object with `pid: undefined`.

This requires pre-populating a lock with an alive PID between the pre-spawn check (which sees no lock/stale lock) and the post-spawn `acquireLock` call.
